# `checks.md` — Verification Evidence

> Executed against the current source tree (`100%` Go standard library, `0` external dependencies). All metrics come from observed command execution.
>
> `go test ./...` runs hermetically offline using mock `security`/`secret-tool`/`op`/`stty`/`osascript`/`sandbox-exec`/`bw`/`psql`/`git`/`claude`/`open` scripts, `httptest` servers (cloud APIs, the Telegram Bot API, the Slack Web API, and the Vercel API), in-process Telegram and Slack stand-ins for the `mintrun init` tests, a fake mintrun app listening on `app.sock` in a short temporary home, and temporary `MINTRUN_HOME` and `HOME` directories. It never calls live cloud APIs, Telegram, or Slack, reaches the mintrun macOS app, mutates `~/.mintrun`, touches the real macOS Keychain or the config of an IDE or AI app, or connects to a database. The real macOS Keychain round-trip test and the real OS sandbox tests are gated behind `-tags integration`.
