# `checks.md` — Verification Evidence

> Executed against the current source tree (`100%` Go standard library, `0` external dependencies). All metrics come from observed command execution.
>
> `go test ./...` runs hermetically offline using mock `security`/`secret-tool`/`op`/`stty`/`osascript`/`sandbox-exec`/`bw`/`psql`/`git`/`claude`/`open` scripts, `httptest` servers (cloud APIs, the Telegram Bot API, the Slack Web API, and the Vercel API), in-process Telegram and Slack stand-ins for the `mintrun init` tests, and temporary `MINTRUN_HOME` and `HOME` directories. It never calls live cloud APIs, Telegram, or Slack, mutates `~/.mintrun`, touches the real macOS Keychain or an IDE's config, or connects to a database. The real macOS Keychain round-trip test and the real `sandbox-exec` tests are gated behind `-tags integration`.
